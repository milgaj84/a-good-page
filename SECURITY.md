# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a problem

Please do not open a public issue for a security problem. Use GitHub's
"Report a vulnerability" button on the Security tab of this repository, or
email the maintainer listed on the repository profile.

Include the version, your operating system and the steps to reproduce.
You should hear back within seven days.

## Scope

A Good Page reads and writes files that you choose, and lists folders you
select as a working directory. It makes no network requests while you write.
Reports about path handling, the Tauri command surface or file corruption are
especially welcome.
